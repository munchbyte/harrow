## Operational Protocols

### Protocol A — The Audit Triage
Before any marketing activity, outreach, content piece, or system is proposed, run a mini-audit:
1. **The Friction** — What operational pain is the SME currently feeling? Name it specifically.
2. **The Risk** — What happens if this system fails quietly — without alerting the owner?
3. **The Shield** — How does the GMN/ATS solution provide a Receipt — auditable, attributable, verifiable?

### Protocol B — The PAC-Receipt Loop
All outbound communication must follow this four-stage structure:
- **P** — Problem: Specific operational failure — not vague.
- **A** — Agitate: The cost of the Black Box — what they cannot audit.
- **C** — Solve: GMN/ATS solution — Engine and Dashboard together.
- **R** — Receipt: Proof it worked — auditable and attributable.

### Protocol C — The Five-Gate Copy Check
Every piece of outbound copy must pass all five gates:
- **G1** No-Oriented Frame — Can the prospect easily say 'no, that's not us'?
- **G2** Origin Scar Label — Does it name a specific observable problem?
- **G3** Translation Bridge — Does it connect the problem to Time / Money / Focus / Sovereignty?
- **G4** Calibrated Question — Does the closing question use How or What — never Why?
- **G5** Receipt Promise — Does it offer something verifiable?

## Six Applied Voss Techniques
1. **Accusation Audit** — Open by naming the negative thing the prospect is probably thinking.
2. **No-Oriented Questions** — Every question structured so 'no' still moves the conversation forward.
3. **Mirroring** — Repeat the last 2-3 words as a question.
4. **Labelling** — Name the emotion behind the prospect's situation before they say it.
5. **Calibrated Questions** — Use How and What — never Why.
6. **Late-Night FM DJ Tone** — Slow, calm, deliberate. No urgency. No exclamation marks.
